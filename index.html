"p는 q이기 위한 ___조건"① p → q 참? → 참이면 충분
② q → p 참? → 참이면 필요
③ 둘 다 참이면 필요충분, 둘 다 거짓이면 아무 조건도 아님
p → qq → pp는 q이기 위한진리집합
참거짓충분조건P ⊂ Q, P ≠ Q
거짓참필요조건Q ⊂ P, P ≠ Q
참참필요충분조건P = Q
거짓거짓아무 조건도 아님포함 관계 없음

자주 나오는 필요충분조건 (a, b, x, y는 실수)

제곱의 합
a2 + b2 = 0 ⇔ a = 0 그리고 b = 0제곱은 0 이상이라 둘 다 0일 수밖에 없음
절댓값의 합
|a| + |b| = 0 ⇔ a = 0 그리고 b = 0
곱이 0
ab = 0 ⇔ a = 0 또는 b = 0
곱이 0이 아님
ab ≠ 0 ⇔ a ≠ 0 그리고 b ≠ 0
둘 다 양수
x > 0 그리고 y > 0 ⇔ x + y > 0 그리고 xy > 0
함정
ab > 0 ⇐ a > 0 그리고 b > 0역은 거짓 (a = b = −1). "a > 0 그리고 b > 0"은 ab > 0이기 위한 충분조건

원소로 비교

p는 q이기 위한 충분조건, q는 p이기 위한 필요조건
충분조건이 되도록
(범위)
p: −1 ≤ x ≤ 3, q: x ≤ ap가 q이기 위한 충분조건 → P ⊂ Q → a ≥ 3
끝점 a = 3이 되는지 따로 확인
필요조건이 되도록
(범위)
p: a ≤ x ≤ 5, q: 1 ≤ x ≤ 3p가 q이기 위한 필요조건 → q ⇒ p → Q ⊂ P → a ≤ 1

필요충분조건이 되도록
P = Q → 양 끝점이 정확히 일치예: p: x2 − ax + 2 = 0, q: x = 1 또는 x = 2 → 두 근이 1, 2 → a = 3
대우로 판단
~q ⇒ ~p 이면 p ⇒ q직접 보이기 어려우면 대우로. 부정끼리 비교하는 문제는 PC, QC의 포함 관계를 뒤집어 생각
외우는 법 — "p는 q이기 위한"에서 p에서 출발하는 화살표가 참이면 충분, p로 들어오는 화살표가 참이면 필요. 집합으로는 작은 쪽이 충분, 큰 쪽이 필요.
